# Núcleo Jurídico

Camada de orquestração das skills de Jurídico & Advocacia.

## Como funciona

O Núcleo recebe a demanda, identifica o objetivo jurídico e seleciona os módulos necessários. As skills existentes permanecem preservadas; o Núcleo atua como camada estratégica sobre elas.

### Fluxo padrão

Fatos → objeto → objetivo → questões jurídicas → provas → teses → argumentos contrários → refutação → providência → revisão → entrega final.
