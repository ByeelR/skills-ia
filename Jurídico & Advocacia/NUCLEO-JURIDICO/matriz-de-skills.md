# Matriz de Skills

O Núcleo deve aproveitar as skills jurídicas existentes no repositório como módulos especializados.

| Objetivo | Skills-base a acionar |
|---|---|
| Diagnóstico de processo | Análise Completa de Processos; Pré-análise; Sistema de Análise Estratégica; Síntese Executiva |
| Tese | Argumentação Jurídica Estruturada; Pesquisa Jurisprudencial; Análise de Tese Vinculante |
| Petição | Gerador de Petições Estruturadas; Modelos de Peças Rápidas; Sistema de Criação de Petições |
| Contestação/réplica | Análise de Casos; Argumentação; Leitura adversarial |
| Revisão | Checklist de Revisão Jurídica Profissional |
| Decisão | Análise de Casos; Pesquisa; revisão estratégica |
| Recursos | Argumentação; Pesquisa; análise de tese vinculante; contrarrazões |
| Quesitos | Análise de Caso; identificação da prova necessária; argumentação |
| Estratégia | Sistema de Análise Estratégica; Recomendações Práticas |

A matriz é um mapa de roteamento, não uma lista para execução obrigatória. O Núcleo deve escolher somente os módulos úteis ao caso.
