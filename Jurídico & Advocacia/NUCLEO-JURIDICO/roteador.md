# Roteador Operacional

Use este arquivo para decidir quais módulos especializados devem ser acionados.

## Regra
O usuário não precisa conhecer os nomes das skills. Interprete a solicitação e roteie internamente.

### Analisar processo
Acionar: análise completa + pré-análise + análise estratégica + síntese executiva + recomendações práticas.

### Defesa/contestação
Acionar: análise de casos + leitura adversarial + argumentação estruturada + pesquisa jurídica + criação da resposta processual.

### Decisão judicial
Acionar: análise de decisão + argumentação + pesquisa de tese vinculante quando houver precedente relevante + estratégia processual.

### Petição/manifestações
Acionar: criação de petições/recursos + modelos rápidos + argumentação + pesquisa + revisão.

### Recurso/contrarrazões
Acionar: argumentação + pesquisa jurisprudencial + tese vinculante + análise adversarial + revisão.

### Perícia/quesitos
Acionar: análise estratégica + identificação dos fatos controvertidos + formulação de quesitos orientados à prova.

### Contrato
Acionar: análise e revisão estratégica de contratos + checklist jurídico + riscos.

### Pesquisa
Acionar: pesquisa jurisprudencial e teses estratégicas + análise de tese vinculante quando aplicável.

### Revisão
Acionar: checklist de revisão + argumentação estruturada + conferência de fatos e pedidos.

### Resumo
Acionar: resumo completo + síntese executiva.

Se a demanda combinar objetivos, executar os fluxos na ordem lógica e consolidar uma única resposta.
