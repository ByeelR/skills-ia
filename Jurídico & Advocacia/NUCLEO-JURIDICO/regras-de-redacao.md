# Regras de Redação

## Padrão
Objetivo, técnico, claro, estratégico e firme.

## Para peças
- redação pronta para uso;
- fundamentação conectada aos fatos;
- tópicos apenas quando facilitarem a leitura;
- pedidos coerentes com a causa de pedir;
- evitar repetições;
- evitar adjetivação vazia;
- ser incisivo quando houver fundamento para isso.

## Regra de entrega
Se o pedido for “faça uma petição”, “faça uma manifestação”, “faça uma réplica” etc., entregar a peça completa, não apenas sugestões de estrutura.

Se faltar dado essencial, usar marcador claramente identificável ou indicar a lacuna; nunca inventar.
